# Native Chrome search

## Contract

- Local Google and Scholar searches use a dedicated system Chrome profile.
- Chrome starts the search before Playwright connects and uses a fixed non-zero debug port.
- The runtime never reads or copies the user's regular Chrome profile.
- Existing parsers, geometric verification, degradation checks, cache, and SearchApi fallback remain active.
- Cloud mode and `SURF_BROWSER_ENGINE=playwright` retain the existing Playwright launch path.

## Falsifiers

- `navigator.webdriver` is true after the late connection.
- Any of three general Google queries or three Scholar queries reaches CAPTCHA or rate limiting.
- Existing parsers return no results from a healthy native Chrome page.
- The native profile is shared with the user's regular Chrome profile.
- SearchApi fallback or the legacy Playwright engine becomes unreachable.

## Deferred

- Long-run CAPTCHA incidence across different IP reputations.
- Native Chrome behavior on macOS and Linux desktops.
- Parallel throughput beyond the current serialized native profile.
