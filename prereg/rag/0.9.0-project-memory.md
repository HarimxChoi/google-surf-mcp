# v0.9.0 project memory preregistration

## Hypothesis

An embedded SurrealDB vertical slice can preserve project, plan, research, and experiment lineage without changing the behavior of searches that do not request local retrieval.

## Scope

- Project create, list, and get
- Immutable plan revisions
- Explicit experiment start and finish
- Automatic search metadata archive
- Extracted content BM25 retrieval
- One-line storage receipt

## Falsifiers

- A plan revision is overwritten.
- An experiment is linked to another project.
- A project retrieves another project's document.
- A research write failure makes live search fail.
- `project_id` omitted changes the live result order.
- RocksDB data cannot be reopened by a new process.

## Deferred

- Dense retrieval
- Code indexing
- Graph sidecar
- External PKM sync
- Automatic experiment outcome inference

## Evidence required

- Focused unit and integration tests
- Full test suite
- Runtime and script typechecks
- Build
- Reopen probe with a temporary RocksDB path
- Diff and comment audit
